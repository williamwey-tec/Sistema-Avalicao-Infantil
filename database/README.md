# Banco de dados

Diretório reservado aos futuros artefatos de banco de dados, depois que entidades, atributos, chaves e relacionamentos forem validados.

Poderá conter:

- schema de criação de tabelas, índices e restrições;
- dados fictícios de demonstração, se necessários;
- documentação de decisões de modelagem.

Ainda não existe schema MySQL implementado. Não devem ser adicionados dados reais de crianças.
