# Repositories

Diretório reservado à futura camada de persistência.

Espera-se que os arquivos desta pasta encapsulem consultas preparadas com PDO, mapeamento de resultados e transações necessárias às operações compostas. Não devem decidir regras pedagógicas ou produzir conteúdo de interface.

Os repositories só devem ser adicionados quando o modelo de dados e as operações correspondentes estiverem definidos.
