# Controllers

Diretório reservado aos futuros controladores HTTP da aplicação PHP.

Espera-se que os arquivos desta pasta recebam e validem o formato das requisições, chamem os serviços apropriados e preparem respostas ou views. Não devem conter SQL nem regras de negócio como imutabilidade ou exclusão lógica de modelos.

Os controladores concretos só devem ser criados quando os respectivos fluxos forem implementados.
