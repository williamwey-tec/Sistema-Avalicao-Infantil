# Models

Diretório reservado a futuros objetos que representem conceitos do domínio, como turma, aluno, modelo avaliativo e avaliação.

Esses objetos devem existir apenas quando ajudarem a expressar dados ou comportamento real da aplicação. Esta pasta não representa uma camada adicional obrigatória e não deve receber classes vazias apenas para completar a árvore.
