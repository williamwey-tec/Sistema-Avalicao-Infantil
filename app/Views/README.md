# Views

Diretório reservado a futuros templates PHP de apresentação.

Espera-se que as views exibam dados previamente preparados pelos controllers e services. Elas não devem executar SQL nem definir regras de negócio.

## Subdiretórios

- `layouts/`: estrutura visual compartilhada.
- `turmas/`: telas relacionadas a turmas e alunos.
- `modelos/`: telas de modelos avaliativos.
- `avaliacoes/`: telas para seleção e preenchimento de avaliações.
- `resultados/`: telas de resultados individuais e consolidados.
