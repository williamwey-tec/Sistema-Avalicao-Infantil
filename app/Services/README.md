Diretório reservado aos futuros serviços e casos de uso do domínio.

Espera-se que os arquivos desta pasta coordenem regras funcionais, como aplicação de avaliações, validação de modelos ativos, preservação do histórico e consolidação de resultados. Não devem depender de HTML, superglobais PHP ou SQL embutido.

Não criar serviços ou interfaces sem um comportamento real que os justifique.
