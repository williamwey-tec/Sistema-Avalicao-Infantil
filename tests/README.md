# Testes

Diretório reservado aos futuros testes automatizados das regras e fluxos implementados.

A prioridade será testar serviços e regras de negócio, especialmente imutabilidade de modelos finalizados, disponibilidade de modelos ativos, exclusão lógica, preservação do histórico e consolidação de resultados.

Testes concretos só devem ser criados junto das funcionalidades correspondentes.
