# Configuração

Diretório reservado a futuras configurações não públicas da aplicação.

Quando a persistência for implementada, poderão existir arquivos de exemplo sem credenciais reais. Configurações locais com senhas ou outros segredos não devem ser versionadas nem ficar acessíveis pela raiz pública.

A versão atual não exige configuração de PHP ou banco de dados.
